# Validation

For the four-device, seven-application evaluation, see the [228 run summaries](../public-evaluation/runs.csv) and the [dataset guide](../public-evaluation/README.md). The summaries report measured runs. The two separately prepared examples exercise provenance review using synthetic content.

## Checking this checkout

From the repository root, run the [device-free test commands](../README.md#tests) and the [two trace commands](../README.md#try-a-provenance-example). The distribution includes tests that use generated inputs and mock devices. Device-derived UI dumps and tests that depend on private fixtures are kept with the research workspace.

The profile audit checks static collector contracts. The session validator checks hashes, references and record consistency. A completed procedure can yield a partial acquisition, as shown in the Telegram example.
